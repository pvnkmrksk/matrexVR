# Cite the software

The repository provides a [CITATION.cff file](../../CITATION.cff) with verified software metadata. It identifies MATREX VR, Pavan Kumar Kaushik as named in the Git history, the repository and release version. No DOI or root license is invented.

## Suggested software citation

Pavan Kumar Kaushik. **MATREX VR**, version 0.3.0. Software. https://github.com/pvnkmrksk/matrexVR

Include the exact release tag or source commit used for acquisition, and retain that identity with the run. A source-modified renderer should cite its commit as well as the project. The software citation is distinct from any publication describing an experiment.

## Stimulus and dependency credits

Generated astronomical sky stimuli use NASA/Goddard Space Flight Center Scientific Visualization Studio's Deep Star Maps 2020, Ernie Wright (USRA), with Gaia DR2: ESA/Gaia/DPAC. The bundled Astronomy Engine source carries its MIT notice and pinned revision. Individual sky manifests record provenance and the represented UTC instant.

Unity, NetMQ and bundled third-party assets retain their own terms and notices. The historical README identified MIT licensing, but the repository has no root LICENSE establishing a project-wide grant. This manual does not infer one from dependency licenses.

Documentation icons are from Lucide, with the ISC license retained beside the local assets. Native gallery images carry their capture provenance. See [sky preview provenance](../site/assets/README.md) and the [gallery](gallery.md).
