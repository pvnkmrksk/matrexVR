Schema field atlasMATREX VR / source manual

Swarm schema fields

This atlas lists 929 emitted property paths from the current swarm runtime/UI schema. It is generated from the actual bundled JSON rather than a second handwritten parameter list.

The schema default is a serialized type default, not a guarantee that it overrides an authored scene/prefab or a field retained by an in-place controller. Production loaders also enforce cross-field rules. A UI slider is a convenience range, not a runtime clamp. See parameter semantics and the exact emitted schema.

Every field has a deep link and is indexed by the manual search. Array items use [] in their path. Nested pre/stimulus/post fields are listed where the schema emits them; repeated names in different phases are distinct paths.
