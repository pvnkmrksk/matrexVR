# JSON configuration

The maintained parameter reference is [configuration-reference.md](configuration-reference.md). It describes every supported field, omitted defaults, units, precedence and historical limits.

Use [StreamingAssets/Templates](../Assets/StreamingAssets/Templates/README.md) for complete editable examples. The older collection is preserved in `StreamingAssets/Archive/Legacy`. Use Templates for complete current starting points and Examples for full variations.

For canonical animal/species/agent names, backward-compatible aliases and reversible UI/JSON editing, see [animal/agent compatibility](animal-agent-compatibility.md). The current UI preserves arbitrary extension fields while runtime parsers interpret supported fields.

Read [Unity 6 controls](unity6-controls.md) and [data formats](data-formats.md) for operator controls and recorded output.
