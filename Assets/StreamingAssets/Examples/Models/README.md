# Try your own GLB

Load `Examples/Sequences/custom-models.sequence.json`. Its three blocks show
the exported bundled locust, a downloaded skeletal model and a downloaded
morph-animation model. The last two also demonstrate editable color overrides.

Open **Appearance → Objects**, select a model, and choose a different GLB.
Copy your file into `Models/` or enter an absolute path. The object card also
offers color and Placement controls. The source GLB stays unchanged; a recording
archives the exact file it consumed.

For mirrored social animals, load
`Examples/Sequences/kannadi-glb.sequence.json` instead. It points
`kannadiModelPath` at the visible `Models/Examples/SimulatedLocust.glb` file.

Asset sources, hashes and licenses are beside the files in `Models/Examples/`.
